demoreel is a command line tool that films your product for you. Give it a URL and a sentence; a cloud browser walks the page, a voice narrates it, and a 1080p demo comes back.

02  how it works

Narration first, then the camera.

The voice is synthesised before anything is recorded, so the browser knows exactly how long to dwell on each scene. Every action is timestamped against the recording clock, and the cursor is drawn from that log — not filmed, not guessed from pixels.

Scan

A stealth cloud browser opens the page and collects the selectors that actually exist on it.

Plan

A language model writes the storyboard, filtered so it can only use selectors from the scan.

Narrate

Each line is voiced and cached by content hash, so an unchanged scene never pays twice.

Render

ffmpeg composites the cursor, click highlights, captions and the mix into one file.

03  on every deploy

The video tracks the product,
not the launch date.

Keep demoreel.yaml in your repo. The Action re-renders it from every deployment, so the demo on your landing page can never drift away from the thing it is demonstrating.

# .github/workflows/demo.yml
on: { deployment_status: {} }

jobs:
  demo:
    if: github.event.deployment_status.state == 'success'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: Kurt-John-Kalwin/demoreel/action@main
        with:
          solari-api-key: ${{ secrets.SOLARI_API_KEY }}

04  cost

Cents, not afternoons.

Two minutes of a cloud browser is a fraction of a cent. The voice and the planner dominate, and both are small. The expensive part of a demo video was never the compute — it was the quiet room, the nine takes and the afternoon.

05  start

Two commands.

npx github:Kurt-John-Kalwin/demoreel init https://your.app
