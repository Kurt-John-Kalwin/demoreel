# Solari capture probe — 2026-09-03 (live, ~2 browser-minutes, < $0.01)

Run from Kurt's Mac with @solarisdk/browser 0.1.3 (patchright-core 1.62.2), Chromium 151.0.7922.34, region us-west.
Scripts: scratchpad/probe/probe.mjs and probe2.mjs.

| Path | Result | Numbers |
|---|---|---|
| `solari.launch()` | works | 2.7 s to a connected browser |
| Playwright `newContext({recordVideo:{dir,size:1920x1080}})` over Solari's remote Playwright server | **WORKS** — server-side recording | VP8 webm, 1920x1080, **25 fps**, 16 s = 1.9 MB; `page.video().saveAs()` pulled it to the client in 1.7 s. `video().path()` throws remotely ("Use saveAs()"). |
| `page.screenshot()` polling | works, slow | jpeg 80 KB in ~1 s first, then ~3.3 fps sustained; 1080p PNG 1.26 s |
| CDP `Page.startScreencast` via `newCDPSession` | works, ack-gated | 7 frames / 6.4 s = 1.1 fps from a home connection (each frame waits for `screencastFrameAck` round trip). Would be far higher from a Solari sandbox in the same region. |
| `chromium.connectOverCDP(cdpEndpoint)` second client on the same session | works | 2.1 s; sees the same context/page |
| `recording: true` + `sessions.downloadReplay()` | works | rrweb NDJSON (gzip content-encoding), 142 KB / 26 events for a 20 s session; 404 for ~10 s after close, then OK; presigned URL expires in 900 s. Event types: 4 Meta (viewport 1280x720), 2 FullSnapshot, 3 Incremental. **It is a DOM recording, not a video.** |

Consequences for a demo-video product:
- Use Playwright `recordVideo` for the raw footage: native 25 fps at any size we ask for, no client-side frame pumping, no ffmpeg needed for capture. Cursor is NOT drawn in Playwright videos, so the cursor must be composited in post from our own action log (which is a feature: a smooth, styled cursor like Screen Studio).
- The rrweb replay is the perfect *secondary* artifact: it is the DOM, so we can re-render it at 4K, diff it between runs, and locate click targets for auto-zoom.
- Screenshot polling and remote CDP screencast are not good enough for smooth video from outside the region; do not build on them.
- Session cost for a 60 s demo capture at $0.10/h is ~$0.002.
