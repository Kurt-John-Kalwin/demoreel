## 4. Solari facts established by live probes (sub-cent, this session)

Full table in `field/probe-capture-2026-09-03.md`; scripts in `demoreel/probes/`.

- `solari.launch()` gives a connected Chromium 151 in 2.7 s. Stealth plus `proxy: "us"` resolves to a residential US egress.
- Playwright `newContext({ recordVideo })` over Solari's remote Playwright server **works**: 1920x1080, VP8 webm, 25 fps, 16 s = 1.9 MB, pulled to the client by `video.saveAs()` in 1.7 s. `video.path()` throws remotely. No cursor is drawn (Playwright behaviour), so the cursor must be composited from our own action log.
- `recording: true` yields an rrweb NDJSON DOM recording (gzip content-encoding), not a video; available about 10 s after close; presigned URL expires in 900 s. Rushes documented a multi-hour outage of this endpoint on 2 Sep. We do not depend on it for video.
- Screenshot polling sustains 3.3 fps; remote CDP `Page.startScreencast` is ack-gated and gave 1.1 fps from a home connection. Neither is a video path from outside the region.
- Sandbox template `base`: Debian 12, Node 18.20.4, Python 3.11, no ffmpeg, apt works (`apt-get install ffmpeg` took 50 s), snapshot of the result took 13.7 s (`snap_...`, deletable, promotable to a template), 1 vCPU even when `cpu: 2` is requested, 2.2 GB free disk, `previewUrl` works. Egress from the sandbox to api.getsolari.com: 7 ms connect, 45 ms total, so an in-region orchestrator would make CDP screencast viable if ever needed. Template `code` is a desktop template and is refused for sandboxes.
- Plan facts still hold from 2 Sep: browser $0.10/h, sandbox $0.057/h, Starter 20 concurrent browsers, 2 VMs, 5 h max session.
